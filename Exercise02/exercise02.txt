Exercise 2: add up the numbers 1 to 10,000,000 with MPI
Run on: Debian Linux container (Docker), Open MPI 5.0.7, gcc 14.2, 8 cpus. Build: make   Run: make run

Each process adds its own range of numbers (process r adds r*N/P+1 .. (r+1)*N/P).
The other processes send their partial sums to rank 0 with MPI_Send, and rank 0 adds
them as it receives them with MPI_Recv.
Compile and run:  mpicc -O2 sum_mpi.c -o sum_mpi && mpirun -np <P> ./sum_mpi

Output:
processes = 1, sum = 50000005000000, expected = 50000005000000, correct = YES, time = 0.003182 s
processes = 2, sum = 50000005000000, expected = 50000005000000, correct = YES, time = 0.001626 s
processes = 4, sum = 50000005000000, expected = 50000005000000, correct = YES, time = 0.000854 s
processes = 8, sum = 50000005000000, expected = 50000005000000, correct = YES, time = 0.000633 s

The answer is 50,000,005,000,000 = N(N+1)/2 for every number of processes.
